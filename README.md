📌 About The Project

AI-LAB-EXPERIMENTS is a collection of Artificial Intelligence lab experiments implemented using Python.

This repository focuses on understanding fundamental AI concepts, search algorithms, optimization techniques, game-playing strategies, and classical problem-solving approaches through practical coding examples.

The main objective is to gain hands-on experience with Artificial Intelligence algorithms and develop a strong foundation in computational problem-solving.

🎯 Objectives
Understand fundamental concepts of Artificial Intelligence.
Implement different AI search algorithms using Python.
Explore intelligent problem-solving techniques.
Understand game-playing algorithms and decision-making.
Practice Python programming through practical experiments.
Develop logical thinking and algorithmic problem-solving skills.
🧠 Experiments Included
No.	Experiment	Description
01	Basic Python Programs	Introduction, input/output and decision-making
02	Even and Odd Number	Conditional statements
03	AI Calculator	Basic arithmetic operations
04	Guessing Game	Simple logical game
05	Breadth-First Search (BFS)	Graph traversal using a queue
06	Depth-First Search (DFS)	Graph traversal using recursion
07	Hill Climbing Algorithm	Optimization and local search
08	A* Search Algorithm	Heuristic-based pathfinding
09	Minimax Algorithm	Decision-making in game trees
10	Alpha-Beta Pruning	Optimization of Minimax search
11	8-Queens Problem	Constraint solving using backtracking
12	Water Jug Problem	State-space search
13	Tic-Tac-Toe	Game logic and decision-making
14	Travelling Salesman Problem	Finding minimum-cost tours

🚀 Getting Started

Follow these steps to explore and run the experiments.

1. Clone the Repository
bash
git clone https://github.com/pandaasish635-bot/AI-LAB-EXPERIMENTS.git

2. Navigate to the Project Directory
bash
cd AI-LAB-EXPERIMENTS

3. Install Jupyter Notebook
bash
pip install notebook

4. Launch Jupyter Notebook
bash
jupyter notebook

5. Open the Notebook

Open AI_ALGORITHM (1).ipynb and execute the code cells to explore the experiments.

Alternative: You can open the notebook directly using Google Colab.
